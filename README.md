# Test 29N

Test político sobre los debates reales de España para las elecciones generales del 29 de noviembre de 2026.

- Web pública: https://menendezpeoe-maker.github.io/
- Todo se calcula en el navegador: sin servidor, sin base de datos, sin registro y sin cookies. Las respuestas se guardan solo en el almacenamiento local del navegador de cada persona.
- Preguntas y posturas de los partidos: `data/preguntas.json` y `data/partidos.json`.
- Herramienta independiente y orientativa; no es una recomendación de voto.
